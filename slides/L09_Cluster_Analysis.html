    01Part 1

    Definition

    Definition

    What Is Cluster Analysis?

    Cluster analysis finds groups of objects such that the objects in a group are similar (or related) to each other, and different from (or unrelated to) the objects in other groups.

    "Unsupervised learning"

    No pre-defined class labels. No examples of object groups are given.

    Distance-based cluster analysis

    Object similarity is measured in terms of distances. Intra-cluster distances are minimized; inter-cluster distances are maximized.

    Why clustering? · Summarization

    Greatly reduces the size of a large data set by picking a representative from each cluster and presenting only those representatives.

    Why clustering? · Outlier detection

    Objects that do not belong to any cluster are outliers.

    Types of clusterings

    Types of Clusterings

    A clustering is a collection of clusters.

    Partitional clustering

    A division of data objects into non-overlapping subsets (clusters) such that each data object is put into one subset (cluster).

    Hierarchical clustering

    A set of nested clusters organized as a hierarchical tree, drawn as a dendrogram. Cutting low in the dendrogram (d1) is a very stringent proximity requirement and gives more, tighter clusters; cutting high (d2) is a very loose one and gives fewer clusters.

    Clustering algorithms

    • Distance-based clustering: K-means and K-medoids; HAC
    • Density-based clustering: DBSCAN (Part 4)
    02Part 2

    Partitioning Methods

    Algorithm

    K-means Clustering

    Partitional clustering. Each cluster is associated with a centroid (center point). Each data object (point) x is assigned to the cluster whose centroid is the closest to x. The number of clusters, k, must be specified. The basic algorithm is very simple:

    1. Select k points as the initial centroids.
    2. Repeat
    3. Form k clusters by assigning all points to their closest centroids. (objects assignment)
    4. Recompute the centroid of each cluster. (centroids update)
    5. Until the centroids don't change.
    Evaluating K-means clusters · SSE of the clustering SSE=∑i=1K∑x∈Cidist(mi,x)2

    mi is the centroid of cluster Ci. Across multiple runs, pick the clustering with the best (smallest) SSE.

    Details

    • Initial centroids are often chosen randomly. The clustering produced depends on the choice of the initial centroids.
    • The centroid is (typically) the mean of the points in a cluster.
    • "Closeness" depends on the type of data: measured by Euclidean distance, cosine similarity, etc.
    • K-means will converge for common similarity measures such as Euclidean distance.
    • Most of the convergence happens in the first few iterations. Often the stopping condition is changed to "no significant changes to the centroids".
    Time complexity
    O(n · K · I · d)

    n = number of points, K = number of clusters, I = number of iterations, d = number of attributes.

    Bisecting K-means

    Each time, pick a cluster to split, based on size, SSE, or both.

    1. Initialize the list of clusters to contain one cluster with all points.
    2. Repeat
    3. Pick a cluster from the list of clusters.
    4. For i = 1 to number of trials: bisect the selected cluster using basic K(2)-means.
    5. Select the two clusters from the bisection with the lowest total SSE, and add them to the list.
    6. Until the list of clusters contains K clusters.

    Limitations of K-means

    K-medoids · worked example

    K-medoids

    Disadvantages of K-means: averages might not make much sense for categorical or binary attributes, and averages could be distorted by noise or outliers. A medoid in a cluster C is a data object x in C such that the total distance from x to all other objects in C is minimum.

    Drag any point. The K-medoids method is the same as the K-means method except that the "representative" used for a cluster is its medoid (instead of its mean). It is more computationally demanding than the K-means method.

    More robust to noise and outliers

    K-medoids is more robust to noise and outliers than K-means. One far-away point drags the mean toward it, but the medoid must be one of the data objects and minimises the total distance to the others, so it barely moves. Press "Add an outlier" and compare.

    03Part 3

    Hierarchical Methods

    Hierarchical clustering

    Hierarchical Clustering

    Produces a set of nested clusters organized as a hierarchical tree, visualized as a dendrogram: a tree-like diagram that records the sequence of merges or splits. Strength: you do not have to assume any specific number of clusters. Any desired number can be obtained by "cutting across" the dendrogram at the proper level.

    Agglomerative

    Start with the points as individual clusters. At each step, merge the closest pair of clusters until only one cluster (or k clusters) is left.

    Divisive

    Start with one, all-inclusive cluster. At each step, split a cluster until each cluster contains a point (or there are k clusters).

    1. Compute the proximity matrix.
    2. Let each data point be a cluster.
    3. Repeat
    4. Merge the two closest clusters.
    5. Update the proximity matrix.
    6. Until only a single cluster remains.

    Agglomerative clustering

    The most popular hierarchical clustering technique. Basic algorithm is straightforward (left). Traditional hierarchical algorithms use a similarity or distance matrix and merge or split one cluster at a time. The key operation is the computation of the proximity of two clusters: next board.

    Density-Based Methods

    Density-based clustering · try it

    DBSCAN: Core, Border and Noise Points

    A cluster is a dense region of points. DBSCAN needs two parameters: a radius Eps and a count MinPts. It does not need the number of clusters. Click a point to see its Eps-neighbourhood.

    • Core point: at least MinPts points within distance Eps, counting itself. (large dot)
    • Border point: not a core point, but within Eps of a core point. (small dot)
    • Noise point: neither core nor border. (×)
    1. Label every point core, border or noise.
    2. Connect core points that are within Eps of each other.
    3. Each connected group of core points, with their border points, is a cluster.
    4. Noise points belong to no cluster.

    Evaluating Clustering Quality

    SSE, cohesion, separation, silhouette · try it

    Measures of Clustering Quality

    • SSE: sum of squared distances of each point to its cluster centroid.
    • Cohesion: average intra-cluster distance.
    • Separation: average inter-cluster distance.

    Silhouette coefficient: combines cohesion and separation, for an individual point i.

    a = average distance of i to the points in its cluster.   b = the smallest, over the other clusters C, of the average distance of i to the points in C.

    s=1−a/b if a < b   (or s=b/a−1 if a ≥ b, not the usual case). Typically between 0 and 1; the closer to 1, the better.

    Reduce

    Label

    Describe each cluster: c-TF-IDF keywords, or a name written by an LLM. Then check the label.

    50 example headlines written for this lecture, in 6 topics plus 2 others. Embeddings, UMAP and HDBSCAN were computed in Python; the 2D picture is a separate UMAP run to 2 dimensions.

    Label · the keyword baseline

    Describing Clusters with c-TF-IDF

    Class-based TF-IDF joins all headlines of a cluster into one document, then asks which words are frequent in this cluster but rare across clusters. It is TF-IDF from Lecture 2, with clusters in place of documents.

    Wt,c=tft,c×log(1+Aft)

    tft,c: share of the words in cluster c that are term t. ft: count of t over all clusters. A: average number of words per cluster.

    Members

    With only 5 to 11 headlines per cluster, most words appear once, so many weights tie; ties are broken by how close the word's embedding is to the cluster's average embedding. On the lab's 1,000 headlines the keywords are clearer.

    AI as a method · check the label, not the prose

    Auditing LLM-Written Cluster Labels

    An LLM reads a few members of each cluster and names it. A label can sound right and still describe only part of the cluster. Coverage is the share of members the label really describes.
