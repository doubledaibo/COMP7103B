    01Part 1

    From Logistic Regression to the Multilayer Perceptron

    Recall Lecture 5

    Logistic Regression Is One Neuron

    A neuron takes a weighted sum of its inputs, adds a bias, and passes the result through an activation function. With the sigmoid as the activation, this is exactly the logistic regression of Lecture 5.

    z=w1x1+w2x2+w3x3+bp=σ(z)=11+e−z
    Same as Lecture 5

    z is the log-odds l = β0 + β1x. The weights are the β's and the bias is β0. The boundary p = 0.5 is the straight line z = 0.

    What changes next

    Swap the activation, connect many neurons in layers, and learn all the weights at once.

    The perceptron · step through

    The Perceptron

    The perceptron is one neuron with a sign activation: ŷ = sign(w·x + b), with labels +1 (●) and −1 (○). It learns one record at a time: when it gets a record wrong, it moves the weights toward the right answer.

    w←w+λ(yi−y^i)xi

    Multilayer perceptron (MLP)

    Hidden Layers and Activations

    2 inputs → 4 → 4 → 1 output: (2×4 + 4) + (4×4 + 4) + (4×1 + 1) = 37 weights and biases to learn.

    • Input layer: one node per attribute.
    • Hidden layers: each neuron takes all outputs of the layer before, weighs them, adds a bias, applies an activation.
    • Output layer: a sigmoid neuron gives p for two classes.

    Why the activation must be non-linear

    Without it, a stack of layers is a product of linear maps, which is again one linear map: the boundary stays a straight line. A non-linear activation lets each layer bend the space.

    Sigmoid σ(z) = 1/(1 + e−z): output in (0, 1).

    tanh(z): output in (−1, 1).

    ReLU(z) = max(0, z): cheap, the usual default.

    Training

    Gradient descent · step through

    Loss and Gradient Descent

    Training means choosing the weights that make a loss small. For a probability output, the usual loss is the cross-entropy, the negative log-likelihood of Lecture 5. Gradient descent repeatedly takes a step downhill: w ← w − η · dL/dw.

    L(w)=−1n∑i[yilnpi+(1−yi)ln(1−pi)]

    The model has one weight: p = σ(w·x), on 30 simulated records. A network has thousands or billions of weights, but each training step is the same idea.

    Backpropagation · step through

    Backpropagation Is the Chain Rule

    Gradient descent needs, for every weight, how much the loss L changes when that weight changes a little: ∂L/∂w. The chain rule: multiply the slopes of the small steps between the weight and the loss. Backpropagation computes these products from the loss backwards, reusing each one.

    The chain rule in one line

    If L changes 3 times as fast as ŷ, and ŷ changes 0.25 times as fast as z, then L changes 3 × 0.25 = 0.75 times as fast as z.

    Validation set

    Held out from training, used to choose when to stop and which settings to keep. The test set stays untouched until the end.

    Early stopping

    Keep the weights from the epoch with the lowest validation loss, as with pre-pruning a tree (Lecture 4).

    Dropout

    During training, switch off each hidden neuron at random with probability p, so no neuron can rely on a few others. All neurons are used at prediction time.

    Hidden Layers Are Learned Features

    In Lecture 5 we lifted ring data with a mapping chosen by hand. A network learns its own mapping: each hidden neuron computes one new feature from the outputs of the layer below, so each hidden layer gives every record a new set of features.     The Embedding Layer

    Words are not numbers. A network's first layer for text is an embedding layer: a lookup table with one learned vector per token. The word vectors of Lecture 2 are exactly such a table, learned from co-occurrence in a large corpus.

    A lookup, then learning

    A token id picks one row of a table with 400,000 rows and 100 columns. Training adjusts the rows like any other weights.

    Similar context, not similar meaning

    The nearest neighbour of late is early: they appear in the same contexts. For a complaint detector that is a warning: the vector says "time word", not "bad".

    GloVe, 100 dimensions, trained on Wikipedia and Gigaword (the vectors used in Lecture 2). Neighbours by cosine similarity.

    Foundation models

    Pretrain Once, Adapt to Many Tasks

    Step 1 · pretraining

    Large unlabelled data

    A very large network learns from raw text (or images, or tables) with a self-made task, such as predicting the next token. No human labels.

    Result

    A foundation model

    General representations of language: its hidden layers carry useful features for many tasks.

    Step 2 · adaptation

    Many tasks

    Classification, extraction, search, summarising: by prompting, by using its embeddings, or by fine-tuning.

    For mining

    A new kind of baseline

    A strong start with few or no labels. Still measured against the classical baseline, on the same test set.

    Same idea as the hidden layers, at scale

    The circles network learned two features for one task. A foundation model learns thousands of features from billions of tokens, and many tasks reuse them.

    04Part 4

    Three Ways to Use a Foundation Model

    Adapting a foundation model to a mining task

    Three Routes

    Route 1

    Zero- or few-shot prompting

    Write the task in a prompt (zero-shot), or add a few labelled examples (few-shot), and ask a large model for the label.

    • No training data
    • Highest cost per record: one model call each
    • Hard to inspect; output can vary
    Route 2

    Embeddings + a simple classifier

    Turn each record into a vector with a pretrained model, then train logistic regression (Lecture 5) on your labels.

    • Needs some labels
    • Cheap and fast; runs locally
    • Inspectable, reproducible
    Route 3

    Fine-tuning a small model

    Continue training a small pretrained model on your labelled records, so its weights adapt to the task.

    • Needs labels, and GPU time
    • Best control over behaviour
    • You own and version the model

    And always: the classical baseline

    TF-IDF + logistic regression (Lecture 2 and Lecture 5) costs almost nothing. Every route has to beat it on the same test set to be worth its cost.

    Practice

    Fix, Log, and Decide Where the Data Goes

    Make LLM labels reproducible
    • Fix the model version (the dated name, not an alias) and the settings, such as temperature 0.
    • Log every prompt, response and timestamp.
    • Run the labelling twice and report the agreement.
    • Keep a small labelled check set, and re-run it whenever the model or prompt changes.
    External API

    Every record leaves your machine. Check the provider's terms on storage and training, and whether you may send personal data at all.

    Local open model

    Data stays on your hardware and the version never changes under you. You pay in hardware and set-up, and small local models are usually less accurate.

    Summary

    Summary

    Neurons to networks

    Logistic regression is one neuron. Hidden layers with non-linear activations let an MLP draw curved boundaries.

    Training

    Gradient descent on a loss; backpropagation is the chain rule. Control overfitting with a validation set, early stopping and dropout.

    Foundation models

    Pretrained on large unlabelled data, then adapted: by prompting, by embeddings plus a simple classifier, or by fine-tuning.

    Choosing

    Compare against the classical baseline on accuracy, cost, speed, privacy and reproducibility. Fix versions; log prompts.
